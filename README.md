# AWS DevOps Kubernetes Capstone

A production-style DevOps project demonstrating end-to-end automation:

- **Application:** Python REST API
- **Infrastructure:** AWS EC2 provisioned via Terraform
- **Configuration:** Ansible roles
- **Containerization:** Docker
- **Orchestration:** Kubernetes via kubeadm
- **CI/CD:** GitHub Actions
- **Monitoring:** Prometheus + Grafana
